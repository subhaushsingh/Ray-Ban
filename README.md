# Ray-Ban Website Clone

This project is a **clone** of the Ray-Ban website, built using **HTML**, **CSS**, **JavaScript**, and modern web design techniques. It replicates the sleek, interactive, and stylish look of the original Ray-Ban website.

## Project Overview
- **Goal:** Recreate the Ray-Ban website to practice frontend development skills and modern design principles.
- **Tech Stack:**
  - **HTML5**: Structured the web pages.
  - **CSS3**: Styled the site with modern design elements and responsiveness.
  - **JavaScript**: Added interactivity and dynamic content.
  - **GSAP**: Smooth animations and transitions for a premium look.
- **Source Tutorial**: Followed a tutorial by [Sheryians Coding School](https://www.youtube.com/@sheryianscodingschool).

---

## Features
- **Modern and Responsive Design**
- **Interactive Elements** using JavaScript
- **Smooth Animations** powered by GSAP
- **Stylish Layout** inspired by Ray-Ban's original website

## Installation & Setup
Follow these steps to set up the project on your local machine:

1. Clone this repository:
   ```bash
   git clone https://github.com/yourusername/rayban-website-clone.git
   ```

2. Navigate to the project directory:
   ```bash
   cd rayban-website-clone
   ```

3. Open the project in your browser:
   - Directly open the `index.html` file.
